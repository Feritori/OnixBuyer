Официальный плагин для скупщика, разработанный мной, OnixMine, для вашего сервера.

Вы можете использовать его бесплатно на своём сервере. Также я предоставляю открытый исходный код (GitHub - Feritori/OnixBuyer). Вы можете свободно адаптировать плагин под свои требования. Плагин разработан с учётом максимальной понятности, и в каждом файле есть подробные пояснения.
При разработке был использован агент KodaCode, если вы используете нейросеть (агентов) прикрепляю вам свой партнёрский код для вас бонус +20% кредитов по вашему плану или тарифу, заранее спасибо.
